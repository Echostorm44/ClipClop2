I couldn't find a clipboard manager that ticked all my boxes so I made my own.  This is the second one I've done.  The first was in Avalonia but this one uses my own CascadeUI framework, it's still C# but it runs on all my pure C# libs like SharpImage that does all the image work in pure C#, no C or C++ libraries.  I'm kinda proud of that.  Anyway, I'm getting off topic.  This is a fairly simple clipboard manager, it is secure, it keeps your entries on your box, it has some good hotkeys and options that make it easy to use.  It runs really light and opens quickly.
